# Privacy Policy for Copy Slack as Markdown

Last updated: September 3, 2026

Copy Slack as Markdown processes the Slack Web message or thread content that a user explicitly chooses to copy. This processing occurs entirely within the user's browser and is used only to convert the selected content into Markdown and place it on the user's clipboard.

The extension does not collect, retain, transmit, sell, or share personal information, Slack message content, browsing activity, authentication information, or analytics data. It does not use external servers, the Slack API, OAuth, advertising, or tracking technologies.

The `clipboardWrite` permission is used only after the user activates the extension's message button, thread button, or keyboard shortcut. The content script runs only on `https://app.slack.com/*` so it can read the Slack content currently visible to the user and provide the requested copy function.

Because no user data is collected or retained by the developer, there is no developer-held user data to access, modify, or delete.

The use of information received from Chrome APIs adheres to the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq), including the Limited Use requirements.

Questions about this policy can be submitted through the project's [GitHub Issues](https://github.com/kokoichi206-sandbox/copy-slack-as-markdown/issues).
